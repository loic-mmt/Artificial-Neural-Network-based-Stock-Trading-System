# Documentation

Je sépare ce qui a été observé, ce qui est implémenté et ce que je veux encore tester.

- [Résumé des benchmarks](benchmark-summary.md) : grandes lignes, décisions et liens vers chaque résultat.
- [Benchmarks](benchmarks/README.md) : fiches détaillées, protocoles et sources.

Les rapports volumineux restent dans `artifacts/`, non suivis par Git. Leurs liens fonctionnent sur une machine qui les possède. Les fiches gardent les chiffres essentiels pour rester lisibles depuis un clone sans artifacts.
